# Security

To report a vulnerability in the Keyio MCP server or the Keyio service, email **info@gokeyio.com** with the subject "Security". Please do not open a public issue. We reply within two working days.

The server is hosted by Keyio; there is no code to patch on your side. To cut an assistant's access at any time, go to Keyio → Settings → Developer → Connected apps → Disconnect, or revoke the API key there.
